## 🧠 About This Repository

This repo covers the core architectures of deep learning, built and trained from scratch in PyTorch. Each notebook is self-contained and runnable in Google Colab — no GPU required for smaller experiments.

```python
architectures = {
    "Feedforward":    "Deep Neural Networks, activation functions, optimisers",
    "Convolutional":  "CNNs for image data — filters, pooling, receptive fields",
    "Recurrent":      "RNNs & LSTMs — vanishing gradients, gating, sequences",
    "Transformer":    "Self-attention, multi-head attention, positional encoding",
}
```

## 📂 Projects

### 🔢 Deep Neural Networks & CNNs
`Machine Learning, Deep NNs, and CNNs/`

Experiments with activation functions (ReLU, ELU, Sigmoid), optimisers (SGD, Adam), and CNN architectures on image data.

**Key concepts:** Backpropagation · Batch normalisation · Dropout · Convolutional layers

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/aryabhardwaj23/DEEP-LEARNING/blob/main/Machine%20Learning%2C%20Deep%20NNs%2C%20and%20CNNs/Deep%20neural%20network.ipynb)

### 🔄 Sequential Data — Overview
`Neural Embedding and Sequential Models/sequential_data_deep_learning.ipynb`

Overview notebook connecting RNN and Transformer experiments. Problem setup, motivation, and results comparison across architectures.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/aryabhardwaj23/DEEP-LEARNING/blob/main/Neural%20Embedding%20and%20Sequential%20Models/sequential_data_deep_learning.ipynb)

### 🔁 Recurrent Neural Networks
`Neural Embedding and Sequential Models/recurrent_neural_networks.ipynb`

Implementing RNNs and LSTMs from scratch. Explores vanishing gradients, gating mechanisms, and sequence-to-sequence mapping.

**Key concepts:** Hidden states · LSTM gates · Bidirectional RNNs · Teacher forcing

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/aryabhardwaj23/DEEP-LEARNING/blob/main/Neural%20Embedding%20and%20Sequential%20Models/recurrent_neural_networks.ipynb)

---

### ⚡ Transformers for Sequential Data
`Neural Embedding and Sequential Models/transformers_for_sequences.ipynb`

Self-attention and the Transformer architecture applied to sequential tasks. Includes multi-head attention, positional encoding, and encoder-decoder Transformers.

**Key concepts:** Scaled dot-product attention · Multi-head attention · Positional encoding · Layer normalisation

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/aryabhardwaj23/DEEP-LEARNING/blob/main/Neural%20Embedding%20and%20Sequential%20Models/transformers_for_sequences.ipynb)
